游泳课的老师都挺好的，林老师的游泳班强度不高，适合摸鱼划水，初级班更轻松，会蛙泳的同学自行训练即可，每节课都有大量同学岸边见习，但是老师也不怎么管，12分钟跑是自己跑自己报，只要报的不太离谱就行，期末考核的时候老师会让技评不到80的同学重新考，因此每个人最终的专项分数都能到90。值得一提的是还是推荐参加趣味运动会这样的加分项目，不然可能和lz一样连续两学期取得尴尬的分数。
