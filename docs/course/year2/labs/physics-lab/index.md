至于实验报告，因为现在可以交电子版报告了，所以完全可以借助AI速通报告，省去大把时间，用markdown格式完成会更快一些，AI可以直接帮我们进行排版，lz用的是这份模板：[大物实验报告markdown样式及模板 - CC98论坛](https://www.cc98.org/topic/6292311)，具体操作就是把报告模板、实验数据和一些参考文档喂给AI，让它帮我们生成报告，然后选择copy as markdown（lz用的是Gemini），直接复制到编辑器里面就可以了，数据分析的图片也可以直接让AI生成python代码来作图，如果用claudecode这类工具的话就更方便了。
