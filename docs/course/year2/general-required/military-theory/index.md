# 军事理论

[大二课程](../../index.md) / 通识必修课程

> **军事理论** · 2学分（程春   92/4.8）秋冬

开卷考试，需要课本，四次雷达点名，电子开卷小测，一篇论文

程春伟大，无需多言，程老师是真的会像传闻说的那样把平时分都拉满，无脑冲就行。老师上课比较有意思，会讲一些有趣的故事，还会进行线上的互动，98上每学期都能刷到相关的帖子。小测在学在浙大线上进行，允许使用AI，只有几道选择题，不用专门准备，点名需要注意一下，如果没点上也可以课间去找老师补签。平常的学习不用怎么上心，lz因为这个学期课程比较满，一般用军理课来补觉（对不起cc老师）。期末开卷考试只需要课本和打印老师为我们整理好的资料就行，考试内容全都是选择题，后面一部分是多选题，少选不给分，所以需要我们翻得快一点，考前有时间可以熟悉一下课本。

要注意的是我们用的这版军理课本已经不印刷了，而新版课本好像还没过审，所以预定教材是没用的，需要自行购买二手书，所以可以提前准备，以防考前没有课本而被迫打印全书。
