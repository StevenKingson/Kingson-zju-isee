# 数字系统设计

[大二课程](../../index.md) / 专业基础课程

> **数字系统设计** · 4学分（刘鹏   83/3.9）春夏

期中+期末考试，四次小测，无点名，无课程设计，需要课本

比较意难平的一门课程，需要课后花很多时间自学，尤其是补充讲义的内容，课上讲的内容实在是不够，期末考的难度也较高，变化多样，拟合效果不佳，今年这张试卷更是跟考模电一样，对TTL电路和脉冲电路的模电原理部分特别钟爱。今年的TTL部分电路图是这次小测的第五题的图：[数电（信电）| 数字系统设计第一次小测（lp） - CC98论坛](https://www.cc98.org/topic/6131307)，但是遗憾的是lz在考前并没有看这份资料，只是记得当初准备第一次小测的时候见过这张图，于是也是完全不记得怎么做。

刘鹏老师的班小测稍微多一点，但是没有课程设计，还是比较推荐选的。小测题目大多出自往年的期中期末卷子，但也有一些新出的题目（也可能只是我没有找到），除了第一次小测都是开卷的，题量和进行的时间也比第一次小测少，建议面向历年题复习。顺带一提，刘鹏老师班的小测和期中是赋分制的，前30%就能得A，只要考了就有基础分，没考的也可以申请补测，还是比较人性化的。

历年卷站内资料比较多，老师也会在他的教师主页和学在浙大上放一些卷子，自学可以看B站王红的网课，还有就是补充讲义部分，补充讲义的控制器部分会有一道大题，微控制器设计应该是必考的，对于这类题可以看这份讲义：[【数电期末复习楼】微控制器讲义补充讲义正文及相关讨论答疑楼 （tag：数字系统设计 数电 842 微控制器） - CC98论坛](https://www.cc98.org/topic/6540831)；此外的补充讲义知识点一般会考判断题，如果实在不知道怎么准备可以直接刷历年卷的判断题，让AI解答，这些考点比较重复，今年考的也基本是往年考过的。
