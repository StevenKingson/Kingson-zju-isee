# 信号与系统

[大二课程](../../index.md) / 专业基础课程

> **信号与系统** · 4学分（郑斌/李军伟   88/4.2）春夏

闭卷期末，一次纸质点名，无小测（每个班不一样），一次实验课作业（与课堂展示），一份课程设计，需要课本

信号与系统的学习还是推荐看胡浩基老师的网课，讲得最为细致易懂，就算开倍速也不影响理解，B站上有剪辑版的视频，看智云也可以。郑老师个性比较随和，理论上不会点名，不过这学期中间有一节课实在是人太少了，于是进行了一次纸质签到，不过听老师后面的说法感觉不一定会计入总评（至于找代签被揪出来的同学就不知道了）。作业是每章一交，每次都会有一些要求用matlab验证的题目，难度不大，AI也能完成。实验课由李军伟老师负责，其中前一次课，讲matlab基础知识，无作业；临近期末（五月底）一次课，讲傅里叶变换在语音识别中的应用，会布置一个数字语音识别的MATLABGUI编程作业，然后在第三次实验课上进行展示，只要进行了展示分数就是80起步，所以基本每个人都上了，所以课后还延长了展示时间，在第四次课上也进行了一节课的展示，这个编程作业有一定难度，lz是借助AI完成的。大家也都比较卷，进行了很多创新功能的实现。第四次课会布置最终的大作业，老师会放出几个选题，我们进行专题研究并写一份报告，难度相比前面的编程作业低一点，就是会占用期末月的时间，最好尽早完成，不要像lz一样拖到临近考试才完成。

期末考试推荐面向历年卷复习，中文班是闭卷考试，如果纯背公式不现实，最好还是在刷题过程中熟悉公式的应用并且了解主要考点，有针对性地复习，最好在期末周之前就把课看完，期末周多花时间刷历年卷。
