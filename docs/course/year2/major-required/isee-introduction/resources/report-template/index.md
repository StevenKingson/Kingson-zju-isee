- [下载模板与校徽（ZIP）](report-template.zip)
- 解压后保持 `template.md` 与 `ZJU.png` 在同一文件夹，用 Typora 打开 `template.md`，填入课程和实验内容后导出 PDF。
- 公开分享前，请删除姓名、学号、签名等个人信息，并检查截图和导出的 PDF。
