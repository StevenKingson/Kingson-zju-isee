# 人工智能

[大二课程](../../index.md) / 专业必修课程

> **人工智能** · 3学分（张岭   89/4.5）春夏

半开卷期末考试，一次雷达点名，5次实验作业，5次理论作业，小组大作业

张老师上课前会放出删减版的课件，目的是让我们上课的时候能够认真听讲，课堂上进行提问的会有加分，但是实际上好像主动提问的人并不多。这门课理论上也是不点名的，但出于和前面的半导体物理一样的原因，在一次调课的时候，来的人太少了导致老师进行了一次雷达点名。至于各种作业和期末大作业，只能说人工智能课程的任务就应该交给人工智能来完成，最后一节课会进行大作业的成果展示，分数会更高一点，不过根据最终公布的得分，lz所在的小组貌似得到的大作业得分比其他组都要低不少，可能是创新还不够吧。期末考试的题型十分固定，面向历年卷复习就行，说实话开卷的A4都不太用得到，因为前面七道题直接套历年卷的公式就行，最后一题MDP题干中直接给出了马尔可夫决策过程的相关公式。不过由于拟合度高，大家的得分都比较高，分数是裸分直接计入，容错较低，要注重计算的准确度。张老师的给分很好，根据班里的成绩公示，基本没有人卡绩。
