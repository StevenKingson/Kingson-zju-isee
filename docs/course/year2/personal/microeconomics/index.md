# 微观经济学（甲）

[大二课程](../../index.md) / 个性修读课程

> **微观经济学（甲）** · 3学分（徐蕙兰   96/5.0）春夏

**修读分类：跨专业课程**

期末闭卷考试（60%），无点名，无小测，三次作业（15%+15%+10%），可以不买课本

这门课是当初舍友推荐选的跨专业课程，lz是补选进入徐老师班里的，分数出来的时候十分惊喜，感谢老师慷慨的给分的同时，我也愿意分享一些学习的经验。至于是否推荐选这门课做跨专业，由于今年的卷子确实考的比较细，如果期末没有花比较多的工夫去复习，有可能成绩会不理想，而且这门课本身的内容也说不上少，要期末速通的话难免会影响其他课程的复习。不过如果真要选的话，我第一个推荐徐蕙兰老师。

首先是平时分的三次作业，前面两次是几道计算题，分别占比总评的15%，基本都是题库里面有的题，就算没找到，询问AI也能得到准确的解答，第三次是20道选择题，占比10%，不限时，可以慢慢用AI查答案。因为徐老师班没有签到和MOOC，平时分全看这三次作业，所以一定要认真做，也不要迟交，过了截止日期再补交会扣分。作业题都是考试的题型，做的时候把题目弄懂也对期末复习有很大的帮助。

然后就是课程的学习，lz前面半个学期是到场听课的，但是临近期中周的时候由于忙其他课程，便开始翘课，后面也懒得补进度就干脆翘到最后了。期末周开始的时候，lz看了一眼老师发的两份样卷，结果发现这门课好像比想象中的难很多，于是开始痛改前非，花了两个晚上把前面的课程二倍速看完了，不得不说徐老师讲的非常好，在保持课件简短不令人头疼的同时还能把概念讲清楚。其实可能平常翘课、期末补天的效率会更高一点，因为lz在补后面的过程的时候发现前面的东西都忘得差不多了，还得回去再看两眼（不过还是不要把所有东西留到期末好一点）。刷完了课程之后lz开始做历年卷，做了4份之后发现选择题和计算题的考点重合度比较高，但是简答题和论述题则需要把概念讲清楚，很多题还有画图的要求，这时候才感受到这门课的难度，但是由于其他课程的考试已经迫在眉睫了，于是决定先放一放，等到考前的那个下午再准备简答题和论述题。在准备其他考试的期间，我其实也抽了点时间看了看计算题（绿皮书课后习题），基本了解了每个模型的做题方法。

考前的这个下午非常关键，lz开始复习前去98搜了一下，正好看到这位课友整理的资料：[微经历年卷集合 （tag：微经 微观经济学 味精） - CC98论坛](https://www.cc98.org/topic/6557240)，里面的内容特别全面，基本能覆盖历年考过的所有题型，比如这次考到的斯威齐模型和食品券的问题都能在里面找到答案。lz当时如获至宝，把里面的题目都看了一遍，逻辑都梳理了一遍，图都画了一遍，在考试的时候也留了个大致印象。由于这门课的历年拟合度比较高，虽说这学期考的比较细，但是大多数也都是能在历年真题里面找到的，所以这份资料是考前一定要看的。

至于学习的资料，lz认为自己去看《西方经济学》和绿皮书不如直接看徐老师的智云，所以也没有买这两本书，至于绿皮书的课后习题和答案，这个帖子里面就有相关资料：[大一xpy分享一下微观经济学笔记/以及一些感想（tag：xyh/许云华/味精/微观经济学/微经/微经笔记/微观经济学笔记） - CC98论坛](https://www.cc98.org/topic/6236397)

历年卷的话，其实看上面的那个合集就行，如果要模拟考场上的题型的话，可以看这个帖子：[微观经济学/微经 历年卷/回忆卷 整理 （19-20 秋冬 到 24-25 春夏） - CC98论坛](https://www.cc98.org/topic/6167337)
