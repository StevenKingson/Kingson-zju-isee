## 第1讲：西方合唱艺术发展概述

### 📌 核心框架

- 合唱艺术课程三大板块：**合唱**（中西方合唱发展/合唱文化/声乐演唱）、**指挥**（合唱指挥训练与实践）、**实践**（合唱本体艺术和技术）
- 西方合唱与宗教密不可分——"没有合唱音乐就没有宗教音乐，没有宗教音乐就没有西方音乐"

### 📌 五大时期特点（必考！）

#### 文艺复兴时期（1-14世纪）
1. 逐渐脱离教会调式，向大、小调发展
2. 基本是**复调音乐**，各声部起着同等作用
3. 作品是**非节拍**的，音乐节奏依从于歌词
4. 声部模仿时常**先后交错**
5. 非协和音的使用受严格限制，变化半音被避用
6. 大量采用**三拍子**的旋律
- **代表作曲家**：拉索（Orlandus Lassus）——经文歌采用多个合唱队（2-5个），《回声》运用卡农模仿

#### 巴洛克时期（17-18世纪）
1. 建立了体系，确立了**和声功能**的运用
2. **数字低音**的即兴变化成为其特征
3. **主调音乐**的比重逐渐增加，复调退居从属
4. 小节线划分**强弱拍率**的作用完全肯定
5. 追求表情和动力，装饰音变化增多
- **代表作品**：亨德尔《弥赛亚》、巴赫《马太受难曲》

#### 古典主义时期（18-19世纪）
1. 力度范围扩大
2. **曲式结构**确立
3. 器乐作用加强
4. 修饰成分减少
5. 主调音乐占主要地位
- 核心理念：理性、秩序、稳定与比例和谐
- **代表人物**：海顿、莫扎特、贝多芬
- **代表作品**：海顿《创世纪》、贝多芬《第九交响曲》"欢乐颂"

#### 浪漫主义时期（19世纪）
1. 强调结构及色调
2. 作者及演唱者的**主观成分**增强
3. 力度、速度的对比**大大增强**
4. **半音阶**的使用
5. **标题音乐**占优势
6. 大多是**主调音乐**
- **代表作品**：威尔第《那布科》《阿依达》、韦伯《自由射手》"猎人合唱"、比才《卡门》"斗牛士合唱"

#### 现代主义时期（20世纪至今）
1. 节拍记号不断更换、节奏复杂
2. 超出调性的限制
3. 采用非乐音的歌唱，着重歌词朗诵语调
4. 采用自然界的音响
5. 广泛运用**室内乐演唱形式**
6. 总谱复杂变化，出现大量新记谱记号
7. 大量**不协和和弦**
- **代表**：潘德列茨基《圣路加受难曲》

### 📌 世界三大清唱剧
1. 亨德尔《弥赛亚》
2. 海顿《创世纪》
3. 门德尔松《伊利亚》

## 第2讲：中国合唱艺术发展

### 📌 五个发展时期（最核心框架，必考！）

| 时期 | 时间 | 名称 | 特点 | 代表作 |
|------|------|------|------|--------|
| 一 | 1900-1930 | **启蒙·学堂乐歌** | 西洋作曲法+民族元素，校园/古诗词题材 | 李叔同《春游》《归燕》、萧友梅《春江花月夜》、赵元任《海韵》 |
| 二 | 1930-1949 | **救亡·民族化** | 爱国抗日救亡，二声部为主，节奏明快 | 冼星海《黄河大合唱》《在太行山上》、黄自《抗敌歌》《旗正飘飘》 |
| 三 | 1949-1979 | **建设·群众化** | 民族素材改编，意识形态印记 | 《远方的客人请你留下来》《牧歌》《长征组歌》 |
| 四 | 1979-2000 | **复苏·多元化** | 民歌/古诗词/群众合唱并进 | 施光南《在希望的田野上》、陆在易《雨后彩虹》 |
| 五 | 2000至今 | **跨界·全球化** | 开放多元，流行/创意/艺术合唱并行 | 彩虹合唱团《张士超…》《再别康桥》 |

### 📌 连线/匹配考点（明确来自课件"听辨挑战-连连看"）
- 《旗正飘飘》→ 第二时期（救亡·民族化）
- 《四渡赤水出奇兵》→ 第三时期（建设·群众化）
- 《村口迎佛》→ 第五时期（跨界·全球化）
- 《春江花月夜》→ 第一时期（启蒙·学堂乐歌）
- 《在希望的田野上》→ 第四时期（复苏·多元化）

### 📌 中国合唱发展总结
1. 在借鉴西洋经验中**起步**
2. 在"洋为中用"并渗透民族音乐元素中**探索**
3. 在发展和凸显民族特征中**壮大**
4. 在多元的创作思想中**创新**

### 📌 合唱中的人文理念
- 合唱的 ABCD 四圈模型：A本体 → B实践 → C认识 → D方法
- "学习合唱之里，思考在合唱外"

## 第3讲：乐理基础知识

### 📌 简谱
- 起源：17世纪法国，法国天主教神父发明
- 18世纪卢梭大力呼吁 → 19世纪法国政府正式认可
- 传入中国：20世纪初由**李叔同**等人从日本引入
- 用阿拉伯数字 1-7 表示七个基本音级，采用首调唱名法

### 📌 音符时值（以四分音符为一拍）
| 音符 | 拍数 | 简谱记法 |
|------|------|----------|
| 全音符 | 4拍 | 1 - - - |
| 二分音符 | 2拍 | 1 - |
| 四分音符 | 1拍 | 1 |
| 八分音符 | 1/2拍 | 1̲ |
| 十六分音符 | 1/4拍 | 1̳ |

### 📌 附点音符
- 附点 = 将原有音符/休止符的时值**增加一半**
- 附点全音符=6拍 | 附点二分=3拍 | 附点四分=1.5拍 | 附点八分=3/4拍

### 📌 音的关系
- 音名：C D E F G A B（基本音级），加升降号为变化音级
- **E-F、B-C 之间为半音**，其余相邻音级为全音
- 两个半音 = 一个全音

### 📌 变音记号（五种）
- ♯ 升记号：升高半音
- ♭ 降记号：降低半音
- ×（重升）：升高全音
- ♭♭（重降）：降低全音
- ♮ 还原记号：还原
- **临时记号**：仅作用于本小节内同音高的音
- **调号**：作用于整行谱各音组同音名的音

### 📌 音程（乐理核心！）
- 定义：两个音在音高上的关系
- **旋律音程**：先后奏出；**和声音程**：同时奏出
- 上方音 = 冠音，下方音 = 根音
- 计算：用"度数"（音级数量）和"音数"（全音/半音数）两方面

**音程性质分类：**
| 度数 | 类别 |
|------|------|
| 一、四、五、八度 | **纯**音程 |
| 二、三、六、七度 | **大/小**音程 |
| 任何度数 | **增/减**音程 |

**音程协和性：**
| 协和程度 | 音程 |
|----------|------|
| 完全协和 | 纯一度、纯四度、纯五度、纯八度 |
| 不完全协和 | 大三度、小三度、大六度、小六度 |
| 不协和 | 大二度、小二度、大七度、小七度及所有增减音程 |

### 📌 音阶
- **自然大调**：全、全、半、全、全、全、半 → 明亮、光辉
- **自然小调**：全、半、全、全、半、全、全 → 暗淡、忧郁
- C大调与a小调为关系大小调

### 📌 三和弦
- 按三度叠置的三个音：根音、三音、五音

| 类型 | 特征 | 听感 |
|------|------|------|
| 大三和弦 | 根-五为纯五度 | 协和、明亮 |
| 小三和弦 | 根-五为纯五度 | 协和、柔美 |
| 减三和弦 | 根-五为**减五度** | 不协和、紧张、向内紧缩 |
| 增三和弦 | 根-五为**增五度** | 不协和、紧张、扩张感 |

### 📌 七和弦
- 四个音按三度叠置，根音与第四个音构成七度
- **属七和弦**：属音（第五级音）上按三度叠置的四个音

### 📌 力度记号（必考！）
| 标记 | 含义 | 标记 | 含义 |
|------|------|------|------|
| pp | 很弱 | f | 强 |
| p | 弱 | ff | 很强 |
| mp | 中弱 | fff | 极强 |
| mf | 中强 | sf | 特强 |
| cresc. / ⟶ | 渐强 | dim. / ⟵ | 渐弱 |
| fp | 强后突弱 | | |

### 📌 速度术语
| 术语 | 含义 | 约BPM |
|------|------|-------|
| Larghetto | 小广板 | 60 |
| Andante | 行板 | 66 |
| Andantino | 小行板 | 69 |
| Moderato | 中板 | 88 |
| Allegretto | 小快板 | 108 |
| Allegro | 快板 | 132 |
| Vivace | 急快板 | 160 |
| Presto | 急板 | 189 |

### 📌 常用记号
- **连线**：不同音高的音唱得连贯
- **换气记号**：∨
- **保持音记号**：—（时值充分）
- **跳音记号**：音符跳跃
- **琶音记号**：竖直波线，和弦由下向上逐个奏响
- **八度记号**：8va（上方提高八度 / 下方降低八度）
- **反复记号**：一房子/二房子、D.C. / D.S.
- **渐慢**：rit.；**恢复原速**：a tempo

### 📌 考核结构
- 平时成绩 40% + 考核 60%（理论10% + 指挥10% + 作品演唱40%）

## 第4讲：合唱呼吸训练

### 📌 合唱五大要素
**体态 → 呼吸 → 发声 → 共鸣 → 咬字吐字**

### 📌 身体五大定位法（重要考点！）
1. **足部根基**——"三足鼎立"（大脚趾球+小脚趾球+脚跟三点均衡受力）
2. **骨盆水盆**——力量中转站（避免前倾后撅，水不洒出）
3. **脊柱轴链**——共鸣通道
4. **肩胛羽翼**——呼吸自由门（避免耸肩、含胸）
5. **头部王冠**——声道准直仪（耳垂→肩峰→股骨大转子呈垂直线；虚顶感）

### 📌 错误姿势的四大后果
| 错误 | 后果 |
|------|------|
| 颈前肌群压迫喉器 | 音域狭窄/高音困难 |
| 膈肌活动受限 | 气息短促/音量微弱 |
| 锁骨上移（胸式呼吸） | 声音僵硬/无泛音 |
| 骨盆倾斜 | 乐句晃动/音准不稳 |

### 📌 胸腹式联合呼吸（核心定义）
- 充分利用**膈肌**和**胸部、腹部呼吸肌肉群**共同控制气息
- 吸气时胸部、腹部、腰部**同时向外扩张**
- 检验方法：横膈膜是否往外扩张
- 地位：歌唱的"基础"和"动力"

### 📌 三种吸气方法
1. **叹气式**吸气
2. **闻花式**吸气
3. **惊讶式**吸气
- 要点：口鼻同时吸气，吸到肺的底部，后腰往两边扩张，**肩膀切忌抬起**

### 📌 歌唱呼气机制——"对抗"
- 吸气肌肉群（保持扩张）和呼气肌肉群（向内收缩）**同时工作**，形成动态平衡
- 气息从后背部斜向前上方推到胸骨弓上（**斜线**，不是垂直柱子）
- **口诀**："吸到哪里从哪里唱，唱的过程中想到吸、吸的过程想到唱"

### 📌 循环呼吸（合唱特有技巧）
- 同声部人在不同地方快速换气并重新回归，保持整体音响不受影响
- 换气时：嘴巴**不能闭合**，**悄声**吸气，从元音进入
- 需与周围队员配合，保持呼吸错落，防止出现相同气口

### 📌 三种呼吸方式
1. 整体一起呼吸
2. 声部之间交流呼吸
3. 循环呼吸

## 第5讲：发声

### 📌 喉头
- 喉头与声带是歌唱的**核心部位**
- 正确位置：**低而自如的稳定位置**（张口吸气时的喉头状态最自然）
- 核心理念：**不是用喉头歌唱，而是通过喉头歌唱**
- 稳定喉头的同时要放松不必要紧张的肌肉（颈部、下腭、肩部等）

### 📌 打开喉咙
- 用 **"打哈欠"** 的状态，下巴放松自然放下而稍后拉
- 歌唱时一直保持 **"吸着唱"** 的状态（感觉上后牙往里拉）
- 这是被动打开喉咙的方式

### 📌 起音（Attack）
- 三个注意要点：
  1. 防止过多过猛的气息冲击声带
  2. 防止声带过于松垮
  3. 防止喉头挤、卡、压
- 起音要做到：发声自然、气息柔和、打开喉咙、声音流动
- **三种起声方式**：硬起声、软起声、舒起声

### 📌 良好的中声区
- 唱歌的基础，应靠前、明亮、轻松流畅、不费力
- 不强调音量，要自然自如、声音灵活
- 最简单的方法：**"贴着咽壁吸着唱"**

### 📌 支点（Support Point）
- 声音发出后必须有支点，掌握呼吸技巧
- 感觉：**声带不长在喉咙里，而长在胸口**
- 每个字不离支点，注意力往胸口想

### 📌 舌的位置
- 舌尖轻抵前下牙，舌根放松，不能后缩，不能压舌根
- 舌头离开后咽壁朝前

## 第6讲：发声共鸣与咬字吐字

### 📌 人体共鸣腔体
**胸腔、喉腔、咽腔、口腔、鼻腔**和**鼻窦**

### 📌 混合共鸣
- 歌唱发声时应用**混合共鸣**方法，掌握好共鸣在各声区里的混合比例
- 各共鸣腔保持一定平衡，不单独强调某一腔体

### 📌 换声区
- 在正确的链条运作下，换声区**不应是个"坎"**
- 链条不断，声音自然穿越

### 📌 口腔共鸣
- 口腔自然上下打开，笑肌微提，下腭自然放下稍后拉
- 声波在**硬腭前部（硬口盖）**集中反射
- **"口腔圆顶"**（咬苹果状），避免下巴僵硬
- 半打哈欠练习是获得口咽腔共鸣的最佳途径

### 📌 哼鸣（Humming）训练
- **闭口哼鸣**：声音从上颚以上发出，嘴似闭非闭，上下齿不咬死，喉头下沉轻轻提气
- **开口哼鸣**：感觉通过眼睛和眉毛歌唱

### 📌 胸腔共鸣
- ⚠️ **千万不要压迫喉头**，不要把浓重的喉音误认为是胸腔共鸣

### 📌 咬字吐字（合唱之"合"的关键）
| 阶段 | 要求 |
|------|------|
| **字头（声母）** | 清晰、有力，叼住弹出 |
| **字腹（韵母）** | 饱满、立起，腔体充分打开 |
| **字尾（归韵）** | 收声后保持形态不变，状态不能松弛 |

- 合唱中可以不收声，直到每句最后一个字（如有韵尾）再收声

## 第7讲：合唱的种类、声部与队形排列

### 📌 合唱分类
- **按声部构成**：同声合唱（童声/女声/男声）vs 混声合唱
- **按人数**：小型(16-24) | 中型(28-36) | 大型(40-80) | 特大型(80+)
- **按表演形式**：有伴奏合唱 | 无伴奏合唱(A Cappella) | 交响合唱
- **按风格**：宗教/民谣/爵士/现代/大众合唱

### 📌 SATB 四声部
| 声部 | 音色特征 | 音域 |
|------|----------|------|
| **S 女高音** | 明朗秀丽、灵动活泼，高音区穿透性强 | 最高到 a² |
| **A 女低音** | 圆润浓厚、结实饱满 | 最低到小字组 g |
| **T 男高音** | 明晰清亮、能柔能刚 | 最高到 a²、b² |
| **B 男低音** | 浑厚低沉、粗旷有力 | 最低到小字组 g/e |

### 📌 队形排列四条原则
1. 女高音常担任主旋律（同第一小提琴），可放在指挥左边
2. 指挥右手灵活，女高音也可放在指挥右边
3. 女高音与男低音（旋律+和声基础）尽量排在一起
4. **音层性写作**时，女高与男高、女低与男低尽量放在一起

### 📌 核心金句
> 合唱是**"合作"**的艺术。

## 第9讲：合唱的和谐统一

### 📌 三大支柱
**声部均衡 ↔ 声部统一 ↔ 音准训练**

### 📌 核心理念
> "让我们唱得像**一个人**。"

### 📌 声部统一的关键——"模仿"
- **母音统一**：同一元音，口型、共鸣位置尽可能一致
- **咬字统一**：声母清晰有力，韵母统一保持，归韵干净利落

### 📌 八种人声分类与声部对应
| 人声类型 | 特点 | 对应声部 |
|----------|------|----------|
| 抒情女高音 | 纯净明亮 | S1 |
| 花腔女高音 | 轻巧华丽 | 领唱/S1 |
| 次女高音 | 高音圆润，中低有厚度 | A1 |
| 女中低音 | 饱满浓厚温柔 | A2 |
| 抒情男高音 | 高音明亮，中音柔和 | T1 |
| 戏剧男高音 | 饱满结实富有激情 | T2 |
| 男中音 | 兼备男高男低音质 | B1 |
| 男低音 | 浓厚的中低音音质 | B2 |

### 📌 三个声区共鸣比例
| 声区 | 真假声比例 | 共鸣侧重 |
|------|------------|----------|
| 高声区 | 假声多于真声，以假声为主 | 强调**头腔共鸣** |
| 中声区 | 真声假声各半 | 以**口腔混合共鸣**为主 |
| 低声区 | 真声多于假声，以真声为主 | 强调**胸腔共鸣** |

### 📌 内外声部
- **外声部**：S + B（框架）
- **内声部**：A + T（需依据外声部调节音量与音色）
- 和声基础声部（低音）音量稍强

### 📌 六种声部角色
主旋律声部 | 副旋律声部 | 和声伴奏声部 | 和声基础声部（低音） | 辅助性声部 | 补充性声部

### 📌 音准
- 音准是和谐的**"生命线"**
- **三大影响因素**：呼吸支持不足、肌肉紧张、听觉不敏锐
- **音程感**是最重要的训练内容

## 第10讲：合唱色调

### 📌 合唱色调定义
通过控制声音的**音量、音色、速度、共鸣位置、咬字**等要素，形成的整体声音的**色彩、明暗、浓淡**等听觉效果

### 📌 色调设计
- **横向设计**：一个声部内，单声部的旋律
- **纵向设计**：几个单乐段有规律地结合并同时进行

### 📌 逻辑重音
- 以**乐汇**为基本依据，每个乐汇中有一个起伏
- 起伏的最高点称为**"逻辑重音"**
- 逻辑重音与节奏、节拍、旋律发展方向紧密相关

### 📌 软起 vs 硬起
| 起声方式 | 感觉 | 色调 |
|----------|------|------|
| 软起 | 像叹气一样，声音柔和 | 偏暖、偏暗 |
| 硬起 | 像喊口令，声音有爆发力 | 偏冷、偏亮 |

### 📌 不同作品类型的音色要求
- 横向旋律 → 各声部音色一致
- 欧洲早期作品 → 音色柔和圣洁（轻声半声）
- 卡农作品 → 需有序有起伏
- 节奏感强作品 → 内声部收敛

### 📌 影响色调的其他要素
- **共鸣位置**：头腔（远/虚）、口腔（中）、胸腔（近/实）
- **咬字**：嘴形圆润=温暖宽厚(靠后)，嘴巴扁=明亮清晰(靠前)
- **速度**：Largo 广板(46-50) → Andante 行板(73-77) → Allegretto 小快板(100-128) → Allegro 快板(110-132)

## 第11讲：合唱团的组建理念与训练要素

### 📌 合唱团理念三要素
1. **艺术定位**：古典严肃/现代流行、本土化/国际化
2. **团队文化**：严谨纪律型/轻松活泼型、追求极致/享受过程
3. **目标愿景**：比赛/丰富校园文化

> "理念没有高低对错，但它像灯塔一样，指引着合唱团所有后续工作的方向。"

### 📌 四大声部比例（关键数据！）
| 声部 | 比例 | 理由 |
|------|------|------|
| 女高音(S) | **30-35%** | 自然音量小但常担任主旋律 |
| 女低音(A) | **20%** | 自然音量稍大于女高音 |
| 男高音(T) | **25-30%** | 需对旋律声部支持 |
| 男低音(B) | **20%** | 自然音量有优势 |

### 📌 客观音量 vs 主观音量
- 频率越高穿透力越强 → 客观音量不大但主观突出
- 频率越低穿透力越弱 → 客观音量大但主观不明显

### 📌 换声点（Passaggio）
- 需要增加气息支持、加强呼吸肌肉对抗、提高和更换共鸣位置的地方
- 换声点**高**的人 → 编入高声部
- 换声点**低**的人 → 编入中低声部

### 📌 不宜进合唱团的声音（三种）
1. 白/沙/摇/抖不能自我调整融合的
2. 个性突出可独唱/领唱的
3. 声带生理条件影响的

### 📌 核心金句
> 合唱是**"合作的艺术"，也是"倾听的艺术"**。

## 第13讲：合唱指挥（一）

### 📌 指挥五大任务
| 任务 | 分类 |
|------|------|
| 社会艺术职责 | **首要**任务 |
| 理解和表达艺术内涵 | **中心**任务 |
| 组织合唱 | **基础**任务 |
| 重塑作品艺术形象 | **最终**任务 |
| 艺术批评与自我反思 | **外延性**任务 |

### 📌 指挥三大要求
较高的音乐素养、扎实的技术基础、良好的组织协调与管理能力

### 📌 姿态要求
- 双脚开度与双肩同宽、一脚略微向前呈稍息状态、重心在两脚之间
- **应避免**：耸肩、提胸、夹肩、塌腰、弓背

### 📌 拍点（Beat Point）
- 定义：每拍从底部的点算起，拍点后的反弹动作包含两个八分音符的时值
- 两种练习途径：1）从上到下像拍皮球；2）从下到上用"推—反弹"形成
- **拍点9条注意点**（课件明确列出，重点）：
  1. 位置约在腰部，不要太高
  2. 弹起和下落线条应成**锐角**不是钝角
  3. "轻轻一推—推起—自然下落"，手势应"弹起"不能"拉起"
  4. 拍点位置应在**手掌掌心**，不在手指或手腕
  5. 运动过程中**手型一般不改变**
  6. 弹起稍快，下落较慢
  7. 可将反弹动作缩小化来练习
  8. 肩臂不要僵硬，处于松弛状态
  9. 先单手练习，再加左手，让右手带动左手

### 📌 曲线与直线
- **曲线**：中慢速度、抒情性作品
- **直线和点**：快速度、弹跳性作品

### 📌 手型与情感表达
| 情感 | 手型 |
|------|------|
| 有力 | 空握或半握拳 |
| 抒情 | 手指稍松软、手型微张 |
| 细致 | 拇指与中指或食指靠拢 |
| 弱/渐弱 | 掌心向下，有抑制感 |
| 强/渐强 | 掌心向上，有扬起感 |

### 📌 手位与声部
- 男/女高音 → 手位和手腕**偏高**（需高位置发声）
- 男/女低音 → 手位和手腕**偏低**（需胸腔位置发声）

### 📌 预示（Cue）
六种方向预示各声部/伴奏/领唱的进入或退出

## 第14讲：合唱指挥（二）

### 📌 起拍三动作
1. **准备**（手臂从身体下方抬起，不超过3秒）
2. **预备拍**
3. **进入发音拍**

### 📌 预备拍
- 一般在起唱**前一拍或前半拍**打出
- **拍点发音必须要有预备拍**
- 后半拍发音可以有也可以无预备拍

### 📌 长音（延长音）
- 超过两拍以上的长音 → 可使用延长处理的变化图式
- 延长音三种记号：**符点、延长线、延长号**
- 音符上方延长号一般默认延长一拍，也可自由延长

### 📌 收拍（Cut-off）
**收拍三动作**：预备拍（终止前一拍）→ 落点（收）→ 反弹

| 类型 | 特点 |
|------|------|
| **强收** | 落点可在上/下/中间，向上反弹；可捏拳；与歌曲情绪力度一致；收后停顿片刻 |
| **弱收** | 幅度较小，五种方式（缩小强收幅度/一划/一捏/一挑/一按）；可反弹也可不反弹 |

### 📌 段落转换三种打法
1. **先收再起**：两个动作，前段收掉再给后段起
2. **收拍即预备拍**：一个动作，收的同时即为后段预备拍
3. **粘结性打法**：不给呼吸，两段连起来

### 📌 主动拍（实拍）
有拍点和有反弹的击拍，适用：
进行曲、舞曲、需明显拍点、引导后半拍进入、控制减慢/渐快

### 📌 控制性挥拍
- 无拍点，线性状态，**犹如用绳索拽动浮船**的力度感
- 适用于抒情歌曲的三种方式：
  1. 只在每小节强拍打柔和实拍
  2. 只在每句开始第一拍打柔和实拍
  3. 全曲打控制性挥拍

### 📌 被动拍（虚拍）
- 无拍点，跟随性击拍（"数拍子"）
- 用途：左手打长音时右手数拍子、领唱/伴奏时小动作数拍子

### 📌 切分节拍与休止打法
- **切分**：双手在切分位置前反弹，在切分音位置上停留并保持相应时值
- **一拍休止**：在休止拍停顿
- **前半拍休止**：类似"后半拍"打法，用反弹动作提示
- **后半拍休止**：直线拍（无反弹），且更短促
- **多拍休止**：双手凝滞般停顿 / 左手停顿右手打虚拍
