# 合唱艺术

[大二课程](../../index.md) / 通识选修课程

> **合唱艺术** · 2学分（李智巧   93/4.8）春夏

期中小组考核+个人考核，期末理论小测+小组考核，不需要课本，五次雷达点名

大家如果缺美育分的而且社恐程度不高的可以考虑补选这门课程，虽然lz是第一轮中彩票选上的，但是lz的舍友和他的几个朋友都是线下签条子成功补选的，就是在线上提交补选申请之后在第一节课到现场把条子交给老师就行，因为这门课容量比较有弹性，所以补选成功率还是很高的（至少对于大三要搬校区的同学来说）。上课内容其实并不是很水，需要我们每节课都进行合唱练习，整个学期要学四首曲目，一个小组大约12-13人，要滥竽充数的话其实也可以，不过期中会有针对个人的考核，就是独唱一句《花非花》的歌词。小组考核的话每个小组一般都会找一两个时间段进行排练，但总体上课外要花的时间不多（只要课上跟着练了就行）。期末的理论知识小测可能需要准备一下，lz是之前学过《视唱练耳》，所以没什么问题，考前可以翻翻98上的历年卷，考点基本重复，下面我也会贴一份AI整理的资料。对于小测，老师课上有一句原话，我只是单纯贴上来，并不做任何引导：“你们下面人那么多，我也看不到你们在做什么。”
