# 生医工转微电子 · 转专业经验


感觉信电学院的转专业看绩点看的更多一点，转专业结果出来基本就是当时面试分组名单从前往后（除了最高的那位4.8＋选手没进，原因我也不好说，可能是面试表现太抽象了），所以有转专业想法的同学们建议从大一开始就卷一卷绩点，尤其是微积分和线代这种硬课的绩点，另外要好好研读转专业政策，提前把转专业需要的课程学了。

面试的话首先要好好准备自我介绍，展现自己的优势和对这个专业的了解，表达想进入这个专业的愿望，后面老师会根据你的自我介绍问一些问题，所以可以提前模拟一下可能会问的问题，思考一下该怎么回答；至于后面的专业相关问题，由于lz当时面试时问的专业问题都比较抽象，所以大家回答的都不是很好，这也从一定程度上弥补了lz专业问题准备不够充分的劣势[ac01]，要准备的话建议提前修读一下信息与电子工程导论这门课，然后在寒假可以看一下信电圣经silicon run纪录片，信电的老师貌似都很喜欢这个，lz当时也把自己学习了这个写进了自我介绍。多的我也不知道说啥了，大家可以看一下站内的其他经验贴：

[如何准备转专业面试---老学长又来胡说八道啦！ - CC98论坛](https://www.cc98.org/topic/6097356)

[专业确认/转专业面试经验帖汇总 - CC98论坛](https://www.cc98.org/topic/5072546)

[大一上寒假转专业信电微电子面试经验贴（tag：信电，微电子，转专业） - CC98论坛](https://www.cc98.org/topic/6203431)

最后提一嘴大家不要因为怕绩点不够高就放弃，lz当时也是因为看了论坛上各种对这一届绩点普遍偏高的论调一度不敢报名微电子转专业，找了一下往年数据也查到平均转入绩点4.6＋，遭到面试重创之后也一度认为自己铁定寄了，但是最后实际上4.3＋也有人转成功，所以最重要的是自信。
