# 生物医学工程——智慧医疗的前世今生

[大一课程](../../index.md) / 通识选修课程

> **生物医学工程——智慧医疗的前世今生** · 1.5学分（张磊/林辉   89/4.5）秋【科技创新】

这门课不是很推荐大家选，任务挺多的，需要写三篇1000字左右的专题报告和期末3000字的课程论文。课堂主要会分四个专题（柔性电子技术、脑机接口、磁共振成像原理与脑科学应用与数字化与未来医疗），分别由生仪学院的四位老师（张磊、张韶岷、吴丹和林辉）讲解，相当于生医工专业的导论课，对生医工有兴趣的同学可以考虑一下。分数组成是专题报告和期末论文各占50%，没有签到可以放心翘，我们当时最终的给分主要在4.2和4.5两档，班上最高94分，没有满绩。
