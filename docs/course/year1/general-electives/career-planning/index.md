# 职业生涯与发展规划

[大一课程](../../index.md) / 通识选修课程

> **职业生涯与发展规划** · 2学分（林恬逸/史扬   96/5.0）春夏【当代社会/创新创业类】

职规是这个学期刚从1.5学分改成2学分的，学制也从小学期课程改成长学期课程，但是相比之下课程任务并没有增加，因此还是比较推荐作为创新创业类学分来修读的，这两位老师是第一次开这门课，都是温柔的女老师，上课还是比较水的。课程任务包括学期初的个人战略十问、中期的职业人物访谈、后面的“他人眼中的我”与职业探索任务，以及期末的生涯发展报告和PPT，除了中期的职业人物访谈和期末的生涯发展报告都挺水的，职业人物访谈需要自己找受访者，由小组开展访谈，最后每个人都要写一篇报告，再由小组内选出两个人作为代表上台报告，得分作为整个小组所有人的得分（没有要求一定要做PPT但是建议还是做一下），期末的生涯发展报告没必要找模板，因为要求字数2000字以内，按老师的要求一块块地完成就差不多了，最后上交作业的时候每个人都要做一份PPT一起上传。期末考试是小组内选出一位同学进行展示，得分作为整个小组所有人的得分，其他小组分别担任点赞官、刀斧手（指出不足）和忍者（提出建议）的任务（期中展示也是这样），是期末周最水的一门考试了。上课的时候建议多代表小组发言，本来以为发言不会记录，因为上课时没有特意登记，但是期末助教会统计同学们上课的座位（每个组的领地都是固定的，组内成员的座位也基本都是固定的），然后可能会根据智云回放来统计发言次数。这门课不需要预定课本，完全用不上。

发帖这天分数才刚刚出来，最终成绩还挺惊喜的，这里分享一点经验吧，如果想取得高分，建议当小组长（这个应该是有加分的），另外课堂发言也很重要（lz因为是小组长所以每次都被迫代表小组发言[ac01]），其他的任务认真完成就行，期中和期末的展示机会可以争取一下（lz只上了期中的，期末的交给组内大佬了）。目前还不知道这个班总体的给分情况，以上只是lz个人的情况，大家选课的时候酌情考虑。
