# 视唱练耳

[大一课程](../../index.md) / 通识选修课程

> **视唱练耳** · 2学分（陈曦   89/4.5）春夏【博雅技艺/美育类】

陈曦老师真的是很好很负责的一位老师，lz是转专业成功后霸王选课选的这门美育，当时别的美育容量都满了，其实一开始我对这种乐理相关的内容很不感兴趣，在这方面也是零基础，加上前面两次课还没选上，没来上，一开始感觉还挺吃力的，但是老师讲的非常细致，每节课开始的时候都会带我们回顾基础，进行一些节奏和旋律的训练和听写，后来也跟上来了。每节课的流程较为固定，先是一开始的小组展示，再是节奏旋律训练听写，然后是新内容的介绍，主要是不同的和弦和调性（老师是真的喜欢官大为老师的nice chord系列，几乎每次都会放一期），接着是一些视唱的训练，最后如果还有时间的话就是赏析环节（一般是华语乐坛的歌手，比如林俊杰、周杰伦和邓紫棋的歌），课后老师会把课件发到群里。至于分数组成，小组展示是自选主题，时长一般是20多分钟，流程大家也都比较熟悉就不过多介绍了，期中有一次节奏和旋律的听写，期末有一次视唱口试（包括节奏视唱、旋律视唱和乐曲片段旋律视唱）和一次理论考试（包括节奏旋律听写、乐理知识考察和乐曲赏析），两次听写考察的话只要平常课前的训练跟着老师认真做都能听出个大概，视唱口试会给每个人十分钟的准备时间，题目是随机抽的，其中节奏视唱和旋律视唱只要平常课上的练习认真跟着老师走也能应付，乐曲片段都是课上视唱练习的曲目，考前老师也会把题库谱子和录音发到群里，有时间的话可以提前准备，背下来就不用担心唱不出来了，期末的理论考试lz花了一个晚上的时间准备，因为平常课上的内容并没有完全听懂，比如说大小调、和弦判断、音程判断和乐谱阅读等内容，对我这种小白还是比较陌生的，复习的花我主要是看老师的PPT和官大为老师的nice chord系列，最后学了个一知半解的就上了，最后的乐曲赏析就是送分了，只要写了就行，老师的给分很好。虽然可能没有其他美育课有意思，但是学这门课确实让lz学会了不少东西，曾经的lz甚至连五线谱都不会看，至少上完这门课lz能迈入乐器学习的门槛了。
