# 电子工程训练（甲）

[大一课程](../../index.md) / 专业必修课程

> **电子工程训练（甲）** · 1.5学分（马洪庆/李培弘/金向东/王子立/龚淑君/李惠忠   93/4.8）春夏

比较花时间的一门课，任务是两个人一组完成，主要有三个项目：基础部分、智能插座、智能小车，要讲的内容有点多，下面lz一个部分一部分讲。

第一部分主要是焊接操作教学、实验仪器使用和电路调试，最终需要我们验收两个焊接成品并写一个实验报告，焊接操作有点考验动手能力，尤其是贴片器件的焊接，手一抖就要歪，过程十分折磨。这里讲一下焊接高分的技巧吧，插件器件的焊接最好焊的饱满一点，虽然教学的时候讲究适中，但是验收的老师好像只认饱满的（也有可能是我对适中的看法太保守了），给分也主要看这点。贴片器件我也没什么经验之谈了，只能说手稳一点吧。实验仪器的使用教学会让我们用这些仪器测一些元器件的参数，这个跟着步骤走就行。电路调试就是让我们测一下之前焊的三块板子的一些数据（两块插件器件的是小组成员每人负责一块，贴片器件为了保证存活率是两个人中间挑一块用就行），这个也是跟着步骤走就行，也可以提前看一下前辈的实验报告，熟悉一下步骤和要测的数据、要拍的照片。最终的报告内容包括一起使用教学、电路调试以及个人总结报告三个部分，小组内两个人都要写自己的，格式也可以参考一下前辈的，但是数据一定要是自己的，不要完全抄袭。（最后会放一个链接，前辈的一些资料可以去这里看）

从第二部分开始，这门课的“魅力”就开始张牙舞爪了，其中软硬件联调的部分最为折磨，涉及一些代码的编写，其过程各种红温，只有做过的人才知道，老师讲的东西也就是念PPT，很多地方都要自己探索（询问DS老师）。首先是要我们焊接一块板子，和后来下发的另一块板子合起来便是我们的智能插座，然后就是一些例行的测量和调试，接下来是软硬件联调和最后的智能插座APP测试。前面的也没什么好说的了，经过第一部分的洗礼大概步骤也熟悉了，这里讲一下软硬件联调的部分。软硬件联调有四个任务，要求我们一二里面和三四里面各选一个，都是一难一易，难的说是给分会高一点（但是占比其实都不大，建议还是以完成任务为重，不要折磨自己），我们小组当时是选了一（难）和三（易），一是用程序实现电流测量结果波动的减小，三是用程序实现异常电压的报警，毕竟我们也没有相关基础，所以这里是在deepseek老师的帮助下完成的，虽说这里好像只要甩给AI就行了，但是实际操作过程中还是会有很多问题，建议大家给AI提供的信息细致一点，尽量以文本文件形式（AI普遍有识图方面的弱点），然后如果跑出来的代码不能正常运行，自己去研究一下代码（还是比较好懂的）然后给AI提出修改意见。最后一部分的智能插座APP就比较轻松，更像是对学院做的APP的一个测评，跟着步骤做一遍很容易的。课堂时间有限，如果没有及时完成所有实验需要联系老师找个空闲的时间来实验室补做（不扣分）。最后的实验报告是小组两个人合作完成，也可以参考一下前辈的格式，里面的数据和图片就不要抄袭了。

第三部分智能小车便是重灾区了，据反馈，很多人在课后也花了不少时间来补做这玩意，建议课上做快一点，提前开搞下一个课时的内容（每个课时会讲一下此次的内容，相当于老师给的一个节奏引导，但是课件内容是完整的，可以自己跟着课件研究，节奏更快一些）。主要工作包括小车的组装、基本动作测试、语音控制测试、传感器测试和最后的程序控制测试，还有一个预习作业，不做没有关系，做了据说有加分，主要内容是对最后的程序控制的步骤的模拟，最后上交一份预习报告，模拟一下还是挺有用的。上面的这些内容都要在公众上提交视频作业，要注意看老师的作业要求，容易坠机的地方包括：车身组号标签未拍摄或模糊、剪辑过多、展示功能不完全。这些视频后面还有一个互评环节，每个人都要评三个组，这也意味着每个组有不同的人评分，如果你的评分和其他人差太多，会影响你自己的分数，所以评分的时候要按照评分细则客观评分，老师也会参与评分所以最终的分数还是比较客观的。从我个人角度来看，这些内容其实还挺有趣的，就像自己组装玩具车，体验它的功能（可能是做的太顺利了不够红温导致的），前面四个内容就是跟着步骤做就行，最后的程序控制需要自己测试并调参数，通过语音控制实现小车的一些动作和自动抓取小球的任务，调试的过程可能有点折磨，但是最终完成的时候还是挺有成就感的，也挺有意思的，前面如果做了预习任务，这里的任务会熟练一点。

智能小车没有实验报告任务，但是最后要写一个课程总结报告，格式没有要求，字数要求1000字，还是很轻松的。

所有任务都按照要求完成就会获得一个不错的分数，上课的时候遇到问题积极询问老师和身边的大佬就好了，这门课主要受诟病的是这些繁琐的过程、某些抽象的老师以及陈年老器材，虽然对专业知识要求不高，但是作为劳育课时的话慎选，有些地方对小白还是不太友好的。另外据说这门课还有由另外三个老师（被称为摸鱼三人组）开的班，相对轻松一点，给分也不错，大家选课的时候可以考虑一下。lz是转专业成功霸王选课的时候只有这个时间段塞得进课表才选这个班的。
