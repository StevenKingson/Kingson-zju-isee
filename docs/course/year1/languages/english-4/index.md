# 大学英语Ⅳ

[大一课程](../../index.md) / 外语类课程

> **大学英语Ⅳ** · 3学分（徐明   86/4.2）秋冬

大英作为公认的绩点杀手，lz取得这个成绩还是挺满意的，这门课的成绩组成主要包括课堂发言、课堂听写、两次小测、两篇课外作文、慧学外语送分项目、一次小组pre、一个线上视频讨论作业、占比只有5%的口试和期末考。徐老师的课堂比较注重口语的表达，经常会点同学起来回答问题，开展小组讨论，课堂内容我也不多说了，大英认真听的人应该不多吧[ac01]。课堂听写是小组内自己批的，所以可以大家一起放放水，小测还是有必要好好准备的，会考一个课文内容的填空，建议考前熟悉一下范围内的课文，单词也是有必要考前背一下的（全靠小测逼我背单词，不然期末肯定背不完），这里推荐一下e志的大英默写器：https://eng.zjueva.net/，用这个背两轮基本就记住了，而且做这个就像闯关一样很有成就感，非常有用。总共要写四篇作文，其中两次安排在小测的时候当堂写，还有两次课外完成，在AI老师的帮助下完成就可以了，如果分数低于11分我们可以重写交给老师将分数改成11分。口试不用花太多时间准备，因为占比不大且给分分差不大。期末考还是比较重要的，听力类型和四六级差不多，但是还多一个听力填空，因为lz听力也不知道怎么练所以就不给建议了，后面的很多填空题考的都是课内的词汇，所以很有必要把单词背一遍。

最后还是建议小朋友们入学前的英语测试分数拿低一点或者干脆不考，不会影响后面的分数的，预置大英四会比较麻烦，虽然从23届开始可以先学四再学三，但是学完四之后就没有预置了，外语分只能靠自己去抽彩票，像lz这个春夏学期就没有外语学了。另外建议大一上把预置退了去选小语种，小语种给分普遍较好，而且一般秋冬学期的小语种主要是面向大一新生的，后面再想选上就难了（真实内心想法：你们不要和老登抢小语种啊）。
