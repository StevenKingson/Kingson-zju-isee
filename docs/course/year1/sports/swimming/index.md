# 游泳（中级）

[大一课程](../../index.md) / 体育类课程

> **游泳（中级）** · 1学分（赵峰   95/5.0）+身体素质课（蓝天宇）春夏

游泳中级是lz霸王选课时从定向越野改的，因为初级没有余量了，中级要求会蛙泳，如果以前没学过游泳的话还是建议从初级还是学，不然不太好跟上。赵老师上课还挺有意思的，经常和同学们聊天扯皮，给分也很好，最终考核是25米自由泳，只要游到终点距离分就满分，技术分也是老师根据动作评判。

蓝老师的身体素质课也挺水的，每次都会提前十几分钟下课，前面的课程都是先走3圈跑两圈然后开展一些专项训练之后签到下课，1000米测完之后便变成了用浙大体艺完成男生3千米女生2千米的打卡后给老师确认后签到走人，又因为这次打卡是在签到之前完成的所以也是能计入打卡总次数的。

这个学期开始多了体育的理论考试，赵老师会在考前在群里发一份划有重点的pdf资料，我们自行打印即可，虽然上面只有游泳相关资料没有身体健康与锻炼方面的知识点，但是应付考试感觉也够了。这个学期没有12分钟跑，用体测分数代替，所以分数可能会低一点。还是建议一下男同胞们注重引体向上的锻炼，这一项的分差还是挺大的，要做6个及以上才会有分数，建议每次打完卡都去单杠吊一会，就算做不起来也对背部的锻炼效果，吊多了就能做了，另外考试的时候不要刻意追求动作标准，一般老师测的时候标准都是很低的，手用不上力脚就蹬两下，下来的时候手不打直稍微弯一点，虽然不太好看，但也不失为应试的技巧了。像lz大一上是班里第二个测的，不知道标准很低所以也没有借力，只做了15个，后面又联系了老师重新测了一次刷到了21个。
