# 乒乓球（初级）

[大一课程](../../index.md) / 体育类课程

> **乒乓球（初级）** · 1学分（叶亚金/沈悦宁   99/5.0）+身体素质课（傅旭波）秋冬

lz选课的时候课程信息上显示老师是叶亚金，但是实际上课的是沈悦宁老师，因为叶老师开了两个班，虽然老师不一样，但是上课内容都是一样的所以不用在意是谁来上，乒乓球初级的内容很基础，因为lz有乒乓球基础所以学的很轻松，但是就算是小白也能应付，期末就考正手攻球，和几位助教对打所以不用担心对面不给力（就算对面打掉了也会停止计时），一分钟内60个来回次数分就满分，技术分老师会根据姿势评分，给分也挺好的，平常练习的时候建议按照老师教的标准姿势来，lz因为以前玩的完全是业余的，姿势不是很标准，所以纠正姿势倒是花了不少时间。推荐学乒乓球的另一个原因是因为教学地点是在室内，在炕州的火炉天气中上体育课有空调吹的救赎感谁懂。

身体素质课是傅旭波老师，总体还是很轻松的，锻炼的强度不是很大，只要你高兴你也可以躲在一边上玩手机，等签到再来。

秋冬学期好像有趣味运动会的加分，参加就能总评直接加2，还是很有性价比的，但是lz因为引体向上和12分钟满分，自我感觉不需要参加，就把机会留给了别人。
