# 线性代数（甲）

[大一课程](../../index.md) / 专业基础课程

> **线性代数（甲）** · 3.5学分（于飞   91/4.5）秋冬

这里的语言风格可能不太一样，因为其他地方都在草稿的基础上改了一下，这里由于苦yf的线代已久于是把相对粗鄙的原文搬上来了，如有不合适请联系lz修改。

牢飞的查老师评分我记得一开始还是9.1，现在已经掉到8.3了，本来是以捞王和从不点名著称的，但是现在好像有点黑化了，具体可以去看看查老师下面的最新评论。yf的上课体验极差，只会拿个电子教材在旁边鬼画符叽里咕噜一顿讲，讲的不仅烂还快，想要跟上他还真要点数学天赋，为数不多的好处是下课早（感觉他自己都比我们想下课），不点名（至少我上课的时候没有点过，不过据说春夏学期好像有一次突击点名了）以及人机小测难度低（但要注意只有答案分没有过程分，一道题分值还大，容易坠机）。总之当时完全靠自学，期末补天靠做往年卷和看教材，对概念大部分都没搞明白，把线代硬生生学成了找规律，这种补天方法大部分情况还挺管用，不过这次期末考对概念理解也有一定要求，于是分数并不是很理想。
