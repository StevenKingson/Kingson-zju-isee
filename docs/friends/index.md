# 友链

茶会的朋友们，和一些值得逛逛的地方。

## 申请友链

如果你也有自己的小天地，欢迎来交换友情链接。学习笔记、ACG、音乐与日常，都可以聊聊。

<div class="friend-actions">

  <a class="md-button" href="https://github.com/StevenKingson/Kingson-zju-isee/issues?q=is%3Aissue%20label%3A%E5%8F%8B%E9%93%BE%E7%94%B3%E8%AF%B7">查看申请进度 ↗</a>

1. 点击“申请友链”，登录 GitHub。
2. 填写网站名称、地址和一句话介绍；头像与互链位置可以选填。
3. 提交后，站长会在同一条 Issue 中回复；通过后再加入下方友链。

想简单打个招呼，也可以到[留言板](../guestbook/index.md)坐坐。
